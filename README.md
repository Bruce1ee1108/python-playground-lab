# Python Playground Lab

A collection of Python projects, experiments, and development notes based on *Python Playground* by Mahesh Venkitachalam.

This repository documents my progress as I work through all 14 projects in the first edition of the book. My aim is to improve my Python programming, problem-solving, debugging, testing, documentation, and version-control skills through practical project work.

## Development Environment

- Operating system: Windows 11
- Python: 3.13.17
- Development environment: Visual Studio Code
- Version control: Git and GitHub

## Objectives

Through these projects, I aim to:

- understand the problem and expected output of each project
- configure development environments independently
- implement each project in manageable stages
- test normal, boundary, and invalid inputs
- document installation and execution steps clearly
- use Git and GitHub throughout the development process
- improve existing implementations after completing the core requirements
- build a public portfolio for UK software development roles

## Development Workflow

Each learning session follows a consistent workflow:
1. Read and define the task.
2. Identify the required inputs and expected outputs.
3. Implement one manageable part of the project.
4. Run and verify the implementation.
5. Record any problems and decisions.
6. Commit the completed work.
7. Push the changes to GitHub.

## Verification

A project is considered complete when:
- it runs from the documented entry point
- its dependencies are recorded
- at least one normal case has been verified
- at least one boundary or invalid case has been considered
- the README contains reproducible instructions
- the final output has been reviewed
- all relevant changes have been committed and pushed
